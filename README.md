# Animated Login Form 🎨

A modern and visually appealing login form built using **HTML and CSS**. This project features a vibrant gradient background, animated input fields, smooth hover transitions, and social media login buttons.

## ✨ Features

- Beautiful pink gradient background.
- Clean and minimal login card.
- Animated input underline on focus and validation.
- Smooth button hover transitions.
- Gradient Continue button.
- Twitter and Facebook login buttons.
- Font Awesome icons.
- Google Fonts integration.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## 📸 Preview

The project includes a clean login interface with animated input fields and colorful social media buttons.
